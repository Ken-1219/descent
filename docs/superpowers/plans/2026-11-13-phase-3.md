# Phase 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Floor 0 playable end to end: a deterministic sim in `src/shared`, a Phaser scene that only draws, a HUD, and keyboard, d-pad and swipe input.

**Architecture:** `step(state, action) → { state, events }` is the only place rules live. The client sends actions, renders `state`, and plays `events`. Fog comes from `visibility(state)`; the glow is decoration only.

**Tech Stack:** TypeScript, Phaser 4.2.1, Vite, Vitest, bun.

## Global Constraints

- The interface and rules are exactly as in `docs/superpowers/specs/2026-11-13-phase-3-design.md`.
- In `src/shared`: integers only, no `Math.random`, no `Date`, no floats, arrays only (never object-key order), and every sort has a total comparator.
- Every tuning number lives in `content.ts`.
- No casts, no `any`, type aliases, named exports.
- Animation lock ≤ 120 ms per turn; one action buffered.
