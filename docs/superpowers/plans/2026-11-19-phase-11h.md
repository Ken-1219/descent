# Phase 11h Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline here) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the 11h spec: a two-line log, dark-room readability (sill, ember, wall edge), new hole and lowered-spike art, torch burned on the end card, truthful bot carvings, the local crowd harness, and the fifth playtest.

**Architecture:** Bot carving truth goes in `src/shared/ghosts.ts`, beside the fixtures it replaces. The server's `seedBots` and the local harness both call it. Display work stays in `scene.ts`, `art.ts` and `game.ts`. The crowd harness extends `local.ts` with the shared `rolloverFloor` and `bot`.

**Tech Stack:** TypeScript, Phaser 4.2.1, Vitest, bun.

## Global Constraints
- Game rules only in `src/shared`; no `Math.random`, `Date`, floats or unordered iteration there.
- Every tuning number in `content.ts` (`BOT_LIE_IN = 4`, `LOG_TURNS = 3`, `BRAZIER_EMBER_RANGE = 8`).
- Colours are tokens; no new colours, no gradients, no casts.
- Simulation goldens unchanged. Generator goldens unchanged.
- Tests first for `src/shared` and `src/server`; visual work verified by Playwright.
