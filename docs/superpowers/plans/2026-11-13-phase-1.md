# Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Tokens, fonts, a code-drawn sprite pipeline with four light levels, and Lab tabs Tokens and Kit.

**Architecture:** `content.ts` owns the palette and the light remap tables. `sprites.ts` turns 1-bit string bitmaps into one runtime atlas canvas, through a pure `tokenAt()` that can be tested in Node. `style.css` mirrors the tokens as CSS custom properties. `ui.ts` builds the kit elements, and the Lab shows everything.

**Tech Stack:** TypeScript, Canvas 2D, plain CSS, Vitest, bun.

## Global Constraints

- Files: only those listed in PLAN.md §5. No new dependencies.
- No raw hex outside `src/shared/content.ts` and `src/client/style.css`.
- No Math.random, Date, floats or unordered iteration in `src/shared`. (`contrast()` lives in `sprites.ts`.)
- Sprites: 16×16 source pixels, at most two tinted layers plus an optional `bg` fill, flip only, never rotate.
- Anti-slop list: PLAN.md §6.
- Spec: `docs/superpowers/specs/2026-11-13-phase-1-design.md`.

### Task 1: content.ts + sprites.ts pipeline (implementer subagent, TDD)

**Files:** Create `src/shared/content.ts`, `src/client/sprites.ts`, `tests/shared.test.ts`.

**Produces (exact):**

```ts
// content.ts
export const TILE = 16;
export const PALETTE = {
  'ink-0': '#0d0f14', 'ink-1': '#171b24', 'ink-2': '#262c3a', stone: '#4a5165',
  pale: '#8b93a7', bone: '#d9cfb8', ember: '#f2a33a', 'ember-deep': '#b5541e',
  wisp: '#8fe3c8', blood: '#d8433b', gilt: '#e8cf6a', bile: '#b7c94a',
} as const;
export type Token = keyof typeof PALETTE;
export type Level = 'lit' | 'dim' | 'edge' | 'remembered';
export const LEVELS: readonly Level[] = ['lit', 'dim', 'edge', 'remembered'];
export const LIGHT: Record<'dim' | 'remembered', Record<Token, Token>>;
// dim: bone,pale→stone; stone,gilt,bile→ink-2; ember→ember-deep; wisp,blood,ember-deep,ink-*→same
// remembered: ink-1,ink-2→ink-1; everything else→ink-2

// sprites.ts
export type Layer = { token: Token; rows: readonly string[] };       // 16 rows × 16 chars of '#' or '.'
export type SpriteDef = { bg?: Token; layers: readonly Layer[] };     // ≤ 2 layers
export type SpriteName = 'floor' | 'wall' | 'spikes' | 'stairs' | 'hero' | 'wisp'
  | 'heart' | 'heart-lost' | 'key' | 'flame' | 'arrow-up' | 'arrow-left';
export const SPRITES: Record<SpriteName, SpriteDef>;
export function tokenAt(def: SpriteDef, level: Level, x: number, y: number): Token | null; // top layer wins, then bg, null = transparent; edge = (x+y)%2===0 ? lit : dim
export type Atlas = { canvas: HTMLCanvasElement; frames: Record<string, { x: number; y: number }> }; // key `${name}@${level}`
export function buildAtlas(): Atlas;   // one column per level, one row per sprite, TILE px cells
export function drawFrame(ctx: CanvasRenderingContext2D, atlas: Atlas, name: SpriteName, level: Level,
  dx: number, dy: number, opts?: { flipX?: boolean; flipY?: boolean }): void;  // 1× source pixels
export function iconCanvas(name: SpriteName, zoom: number, opts?: { flipX?: boolean; flipY?: boolean }): HTMLCanvasElement; // 16·zoom px, image-rendering pixelated
export function contrast(a: string, b: string): number;  // WCAG 2 ratio of two '#rrggbb'
```

- [ ] **Step 1: Write the failing tests** in `tests/shared.test.ts` (plain `import { test, expect } from 'vitest'`):
  - `contrast(PALETTE.bone, PALETTE['ink-0'])` ≥ 4.5, `bone`/`ink-2` ≥ 4.5, `pale`/`ink-2` ≥ 4.5, and `contrast('#000000', '#ffffff')` ≈ 21.
  - For each of `dim` and `remembered`, `LIGHT[level]` has every `PALETTE` key, and every value is a `PALETTE` key. `remembered` values are only `ink-1` or `ink-2`.
  - Every `SPRITES` entry has 1 or 2 layers, each with exactly 16 rows of exactly 16 chars matching `/^[#.]{16}$/`.
  - `tokenAt` returns the layer token on a `#` pixel at `lit`, `LIGHT.dim[token]` at `dim`, the lit token at an even (x+y) and the dim token at an odd (x+y) for `edge`, the bg token where no layer pixel exists, and `null` with no bg.
- [ ] **Step 2:** `bunx vitest run`. Expected: FAIL (modules missing).
- [ ] **Step 3:** Implement `content.ts`, then `sprites.ts`. Bitmaps are readable placeholders; Phase 2 replaces them. Guidance:
  - floor = bg `ink-1` with 3–5 sparse `bone` dots.
  - wall = bg `ink-2`, a `stone` brick pattern and a `bone` top-edge highlight row.
  - spikes = floor-like bg `ink-1`, `blood` triangles.
  - stairs = `bone` steps descending into an `ink-0` gap.
  - hero = a hooded figure about 10 px tall in `bone`, with a 2–3 px `ember` flame on the right side.
  - wisp = an 8×10 teardrop in `wisp` with two `ink-0` eye holes (as `.` gaps).
  - heart = `bone` outline + `blood` fill; heart-lost = the same outline layer only.
  - key = `gilt`. flame = `ember` with an `ember-deep` core. arrow-up and arrow-left = `bone` chevrons.
  - Keep sprites asymmetric where natural (PLAN.md bans symmetric auto-generated-looking sprites).
- [ ] **Step 4:** `bun run check`. Expected: green.
