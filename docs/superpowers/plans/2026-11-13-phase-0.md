# Phase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A local Vite harness, Vitest with `@devvit/test`, an empty Lab page, and recorded template facts.

**Architecture:** `vite.local.config.ts` serves `src/client` as plain Vite, with no Devvit plugin, so Playwright can drive it. `npm run check` = `tsc --build` + `vitest run`. Production still builds through `vite.config.ts` and the Devvit plugin.

**Tech Stack:** Vite 8.3.7, TypeScript 6.0.3, Vitest (latest compatible), @devvit/test 0.15.3.

## Global Constraints

- Files only from PLAN.md §5. Don't touch the Phaser or Devvit versions.
- No new runtime dependencies. Dev deps: `vitest`, `@devvit/test@0.15.3` only.
- Install with `npm install -D` (allowed). Never `rm -rf` or `curl`.
- Spec: `docs/superpowers/specs/2026-11-13-phase-0-design.md`.

### Task 1: Harness, scripts, smoke test, Lab (implementer subagent)

**Files:**
- Create: `vite.local.config.ts`, `src/client/lab.html`, `tests/server.test.ts`
- Modify: `package.json` (scripts, devDeps), `tools/tsconfig.vite.json` (include), `.gitignore`

- [ ] **Step 1: Install dev deps:** `npm install -D vitest @devvit/test@0.15.3`
- [ ] **Step 2: Write the smoke test**, `tests/server.test.ts`:

```ts
import { expect } from 'vitest';
import { createDevvitTest } from '@devvit/test/server/vitest';

const test = createDevvitTest();

test('set-if-absent writes once', async ({ redis }) => {
  await redis.set('k', 'a', { nx: true });
  await redis.set('k', 'b', { nx: true });
  expect(await redis.get('k')).toBe('a');
  expect(await redis.hSetNX('h', 'f', '1')).toBe(1);
  expect(await redis.hSetNX('h', 'f', '2')).toBe(0);
});
```

- [ ] **Step 3: Add the scripts** in `package.json`: `"local": "vite --config vite.local.config.ts"`, `"check": "tsc --build && vitest run"`, and set `"test:unit": "vitest run"`.
- [ ] **Step 4: Run** `npx vitest run`. Expected: 1 passed. If the Devvit plugin in `vite.config.ts` breaks Vitest, add a `test: { include: ['tests/**/*.test.ts'] }` block to `vite.local.config.ts`, point the vitest calls in scripts at `--config vite.local.config.ts`, and note it.
- [ ] **Step 5: Create `vite.local.config.ts`:**

```ts
import { defineConfig } from 'vite';

// Local harness only: plain Vite over src/client, no Devvit plugin, never used for production builds.
export default defineConfig({
  root: 'src/client',
  publicDir: '../../public',
  server: { port: 5173, strictPort: true },
});
```

  Then add `"../vite.local.config.ts"` to `include` in `tools/tsconfig.vite.json`.
- [ ] **Step 6: Create `src/client/lab.html`**: doctype, `lang="en"`, charset, viewport, `<title>Descent Lab</title>`, `<h1>Descent Lab</h1>`. No script, no styles; tokens arrive in Phase 1.
- [ ] **Step 7: Add to `.gitignore`:** `shots/` and `.playwright-mcp/`.
- [ ] **Step 8: Verify:** `npm run check` is green. Then run `npm run build` and `ls dist/client`; there must be no `lab*` file, and `grep -rl "Descent Lab" dist` must be empty. If `lab.html` appears in the build, report it; don't hack around it.
