# Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Every cast member on screen with animations: pack frames re-timed per §15.4, plus new art for the wisp, the wall torch and death-to-wisp. Lab tab Cast.

**Architecture:** Animations are data (`ANIMS`) plus one pure timing function (`frameAt`), so the Lab and, later, Phaser read the same table. Pack frames are referenced by `PACK` keys; our own frames by `SPRITES` keys.

**Tech Stack:** TypeScript, Canvas 2D, Vitest, bun.

## Global Constraints

- Do not redraw pack frames. New art only for: wisp, wall torch, death-to-wisp.
- Every frame is at least 84 ms (12 fps or slower). Every animation has at least one hold (max ms > min ms).
- No casts, no `any`, named exports, type aliases. No hex outside `content.ts` and `style.css`.
- Only files in PLAN.md §5.
- Spec: `docs/superpowers/specs/2026-11-13-phase-2-design.md`.

export type Frame =
  | { src: 'own'; name: SpriteName; dy?: number; tint?: Token }
  | { src: 'pack'; name: PackName; dy?: number; tint?: Token };
export type Anim = { frames: readonly Frame[]; ms: readonly number[]; loop: boolean };
/** Index of the frame showing at `elapsed` ms. Loops wrap; one-shots clamp to the last frame. */
export function frameAt(anim: Anim, elapsed: number): number;
export const ANIMS: Record<string, Anim>;
